# v0.2.0-rc.2 — GitOps Preview Toolkit

Second release candidate for the plugin-based toolkit. Install the host and sibling plugins from the same release archive. This is a prerelease, not a stable promotion.

## Highlights

- Redesigned HTML report with an overview for quick reviews and a focused resource-by-resource workspace for larger changes. Includes light/dark themes, scoped navigation, local review progress, and a clearer Base → Target header.
- Cluster-wide findings are explicitly separate from individual resource diffs. Policy and AI classification provenance remain distinct; local review marks do not imply approval.
- Flux Kustomization patches, images, components, name prefixes/suffixes and common metadata are now rendered through the supported build pipeline.
- Helm chart values files support ordered merging, default replacement, missing-file handling and source-path confinement.
- Flux ResourceSet fan-out supports inline inputs, Static providers and pre-baked provider snapshots.
- New `gitops-preview doctor` command checks configuration, roots and plugin compatibility; explicitly enabled Crossplane checks include the pinned engine version.

## Security

- Updated the minimum Go version and action builder to Go 1.26.11 and `golang.org/x/net` to v0.60.0, with required transitive updates. These address the newly reported standard-library and HTTP/2 vulnerabilities, including GO-2026-6809 and GO-2026-6859, which require later fixes than Go 1.26.9. The fail-closed vulnerability gate and existing reviewed Docker SDK exceptions are unchanged.

## Usage

```sh
gitops-preview doctor . -k clusters/production
gitops-preview doctor . -k clusters/production --output json
gitops-preview diff -k clusters/production
```

Complete archives include `gitops-preview`, `fmp`, `gitops-preview-flux`, and `gitops-preview-crossplane` for Linux/macOS on amd64/arm64. The external Crossplane controller engine is installed separately when needed.

## Boundaries

Doctor is a prerequisite check, not render validation. Flux `postBuild.substituteFrom`, controller decryption and HelmRelease `chartRef` remain unsupported. See [rendering support](../rendering-support.md) and [report controls](../report-review-workspace.md).

The report remains a single offline HTML artifact. Semantic field summaries and full producer ancestry visualization are future work.
